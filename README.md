# dsh-skin · 给 DeepSeek Harness 桌面端换肤

> **中文** ｜ [English →](README.en.md)

给 DeepSeek Harness 桌面端换一张**全屏背景图**，并**按图片自身的明暗自动把界面文字翻成黑字或白字** —— 背景再花，字也看得清。

- 壁纸想换就换：单张、整个文件夹批量导入，还能按间隔自动轮换。
- 字永远看得清：把图切成小块统计明暗，整套文字翻到黑或白，**不做第三种颜色**。
- 提示音自己挑：内置 4 个轻音效，也能传你自己的音频（任务跑完、要你判断都会响）。
- 一切存**本机文件**：不联网、不上传；重启不丢。

插件名 `@local/dsh-skin`｜界面里显示为 **换肤（Skin）**｜许可 [MIT](LICENSE)

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| **换背景图** | 选单张或整个文件夹批量导入；横图铺满，竖图可选「原图 / 居中 / 铺满 / 模糊填充 / 立绘贴侧」，两侧可加模糊过渡 |
| **文字自动配色** | 把图切成 **12×12 块**统计黑/白面积占比 → 黑块多配**白字**、白块多配**黑字**、黑白接近按主题默认。**只有黑白两种颜色**，不做第三种 |
| **背景明度（透明度）** | 一根滑杆 **0~40%**：往左图更清楚、往右字更清楚；每张图会给一行「建议最低值」（**只是建议，不挡手**） |
| **三个使用模式** | **专注 35%** / **正常**（按图自动：暗图 12% / 亮图 6%，可再手调）/ **休闲 5%** |
| **悬浮球 + 面板** | 单击开面板、双击开关自动换肤（球上出绿点）、拖动记位置、把图片拖到球上直接导入 |
| **自动换肤** | 可设间隔（最短 1 分钟）自动轮换图库里的图 |
| **中英双语** | 面板最顶上「中文 / Chinese｜English / 英文」一键切换，**默认中文**，选择会记住 |
| **新手引导** | 第一次装的人打开面板会自动跳出 4 步引导；之后可点「新手指引」再看 |
| **任务完成提示音** | **两种情况都会响**：① 任务真的跑完 ② 需要你来判断（工具要你批准 / 要你回答问题） |
| **自定义音效** | 内置合成「叮」+ **自带 4 个小音效**；可批量添加自己的音频（单个 ≤8MB、最多 30 条 / 合计 ≤200MB） |
| **一键还原** | 面板最顶上「恢复默认界面」撤掉背景与配色改动，**图库不会清空** |

## 二、为什么做这个

桌面端的主题是给纯色界面设计的：**一换上有明暗起伏的照片当背景，就会出现"白底白字、黑底黑字"看不清的地方**。市面上常见的做法是给整张图压一层半透明黑，代价是图片被压灰、失去质感。

这个插件的思路是**把配色交给图片自己**：先判断这张图在哪些区域偏暗、哪些偏亮，再把整套文字颜色翻到对比度更高的那一侧，同时用尽量低的遮罩保住原图观感。所以：

- 背景图尽量**不压灰**（默认遮罩很低，专注模式才压到 35%）；
- 文字**要么全黑要么全白**，不做花活 —— 两种颜色的对比度最容易做稳；
- 面板上每一个数值都是**可解释的**（见第六节），不搞"魔法数值"。

## 三、安装

### 方式 A：应用内安装

1. 打开桌面端左侧 **「插件」** 页面；
2. 点右上角 **「添加」**，按弹窗提示填来源（本地文件夹 / 包名 / 仓库地址，取决于发布方式）；
3. **重启桌面端**。

### 方式 B：手动放文件

1. 把本仓库的 **`plugin/`** 整个文件夹放到：
   `%USERPROFILE%\.dsh\profiles\desktop\node_modules\@local\dsh-skin\`
2. 打开 `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml`，加一段（三个路径换成你自己的目录，目录不用自己建）：

```yaml
- insert:
    - id: dsh-skin
      name: '@local/dsh-skin'
      config:
        stateFile: 'D:/dsh-skin/state.json'
        libraryFile: 'D:/dsh-skin/library.json'
        imageDir: 'D:/dsh-skin/images'
```

3. **重启桌面端**。

### 装好了怎么确认

设置里能看到 **「换肤（Skin）」** 那一栏，屏幕右侧（输入框上沿附近）出现**悬浮球**。

## 四、用法

| 操作 | 效果 |
|---|---|
| **单击悬浮球** | 打开 / 关闭面板 |
| **双击** | 开 / 关自动换肤（球右上角出现**小绿点**＝开着） |
| **按住拖动** | 挪位置；**松手会记住**，重启还在 |
| **把图片文件拖到球上** | 直接导入这张图 |
| **Esc / 点面板外** | 关掉面板 |

## 五、文字颜色为什么自己变

1. 把背景图缩成 **12×12 格**，逐格算平均亮度；
2. 统计「偏暗的格」和「偏亮的格」各占多少（以及整图平均亮度、主色调）；
3. 按占比决定**整套文字翻成黑字还是白字**：黑块多 → 白字；白块多 → 黑字；黑白差不多 → 交回主题默认（暗色主题白字、亮色主题黑字）。

**为什么只有黑白两色**：曾经有一档"白底用蓝字"的例外，实测在亮图上对比度只有 **2.55:1**（黑字有 **11.22:1**），反而更糊 —— 已撤掉。宁可少一个颜色，也要每个像素都看得清。

## 六、面板逐项

面板从上到下：

1. **语言 / Language** —— 「中文 / Chinese」「English / 英文」，一键切换（默认中文）
2. **新手指引** 按钮 —— 随时把引导叫出来
3. **恢复默认界面** —— 撤背景与配色（不动图库、不动语言、不动音效开关）
4. **使用模式** —— 专注 / 正常 / 休闲（专注、休闲会锁定下面的滑杆，并写明原因）
5. **背景明度** —— 0~40% 滑杆 + 一行「建议最低」
6. **图库** —— 缩略图（一次渲染 60 张，滚动自动续）、换一张、选图片、整个文件夹
7. **竖图铺法** —— 原图 / 居中 / 铺满 / 模糊填充 / 立绘贴侧 + 两侧模糊过渡
8. **自动换肤** —— 间隔选择（关闭 / 1 / 5 / 15 / 30 / 60 分钟）
9. **任务完成提示音** —— 开关 / 音量 / 试听 / 添加音效（可多选）/ 音效列表 / 容量读数
10. **这张图的读数** —— 深浅、亮度、建议最低

> **提示音要出声，必须先点一次「试听」** —— 浏览器规定：没有用户点击过，网页不许出声。

## 七、数据存在哪

| 东西 | 位置 |
|---|---|
| 设置 | 配置里 `stateFile` 指的那个 `state.json` |
| 图库索引 | 配置里 `libraryFile` 指的 `library.json` |
| 图片 | 配置里 `imageDir` 指的 `images/`（一张图两个文件：原图 + 缩略图） |
| 自定义音效 | 跟图片目录同级的 `sounds/`（索引 `index.json` + 每个音效一个文件） |

这些**全是本机文件**，不在仓库里，也不会被上传。

## 十、开发者：验证脚本

`verify/` 下都是**离线可跑**的判据脚本（`node verify/xxx.cjs`），核心思路：**判据从源码里抠出来，不手抄常量** —— 免得改了代码测试还绿。

```powershell
node verify/full_verify.cjs        # 页面逻辑全量契约（用 React 桩真跑）
node verify/panel_order_check.cjs  # 面板各段的顺序、中英文案键集合必须一致
node verify/bell_check.cjs         # 提示音全链（含"需要人工判断"）
node verify/bell_signal_check.cjs  # 什么时候该响／什么时候不许响
node verify/mode_wash_check.cjs    # 三档模式的遮罩取值
node verify/sound_quota_check.cjs  # 音效三道闸 + 首装铺自带音效 + 撤掉的品牌音效自动清掉
node verify/version_check.cjs      # 版本号 ↔ 快照哈希 ↔ 界面标题三处对账
```

- 其中 `wash_audit` / `static_surface_audit` / `solid_fill_check` / `ctx_tokens` / `theme_apply_probe` 要读桌面端安装目录里的 `app.asar`（按 `%LOCALAPPDATA%\Programs\DeepSeek Harness\resources\app.asar` 推路径），装别处会读不到、**报错即止，不改任何东西**。
- `full_verify` 在没有 `state.json` / `library.json` 时会用**内置样例数据**，所以 clone 下来直接能跑。

## 十一、常见问题

**Q：装了没反应？** 先**重启桌面端**；再确认设置里能看到「换肤（Skin）」那一栏。

**Q：悬浮球找不到了？** 可能被拖到屏幕边角。重启桌面端会回到输入框上沿附近（拖动位置会被记住，这是故意的）。

**Q：换图后字看不清？** 把「背景明度」往右拖两格。插件已自动判黑白字，还看不清说明背景太花。

**Q：图库会丢吗？** 不会，图片和索引都是本机文件。「恢复默认界面」只撤背景与配色。

**Q：提示音不响？** ① 开关没开；② **没点过「试听」**（浏览器要求先有一次点击）；③ 自定义音效没选中（列表里那条要有 `✓`）。

**Q：提示音提前响 / 响错时候？** 提示音只在两种情况响：**任务真结束**、**需要你判断**（要批准 / 要回答）。若你觉得响错，把"当时在干什么、早了多久"记下来提 issue。

**Q：加音效说超限？** 上限：单个 8MB、最多 30 条、合计 200MB。提示音 1~3 秒的 mp3 通常只有几十 KB。

**Q：能只用图不换字色吗？** 不能单独关 —— 文字翻色是这个插件的核心（不翻就会白底白字）。要纯净原图体验，把「背景明度」拉到 0 并接受可能的看不清楚。

## 十二、第三方素材

`plugin/assets/sounds/` 里自带 4 个小音效（叮的一声 / 咚咚 / 丢硬币 / 拔剑），**均为合成/录制的轻提示音，仅作为功能演示与个人使用**，不含任何第三方品牌音频。若你要把本仓库用于商业用途或再分发，请自行替换这些音频。

**关于历史版本快照（`releases/`）**：这里保留了逐版的可回滚快照，其中 **v1.5.2 ~ v1.5.5 当年带过 5 条可识别品牌的音效**（名字里含 CS / QQ 的那几条）。**从 v1.6.0 起本仓库不再分发它们** —— 这几个快照里**已经不含**那几个音频文件，对应的《文件清单》里用一个「（品牌音频 N 个，已撤除）」的表格行注明了；快照里保留的仍然是无品牌的音效。
