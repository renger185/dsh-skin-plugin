## 你问的那 9 是什么

是「**自动底线**」—— **每张图**按它最糟的那块地方算出来的「字会看不清的下限」。你 10-18 晚上点头过（原话「一起都改」），当时的做法是**硬挡**：

- 它当了滑杆的左端（所以你这张图从 9 起）；
- 而且还在后台把数值往上抬（拖到 0 也会被抬到 9）。

结果就是：**写着 0~40，实际拖不到 0** —— 你要的根本没落地。更糟的是它还会悄悄改昨晚刚定的两个档（休闲 5% 会被它抬到 9%）。

## 改了什么

| | 改前 | 改后 |
|---|---|---|
| 滑杆左端 | 这张图的底线（你这张是 9） | **0** |
| 拖到 0 | 被抬到 9 | **就是 0**，图原样透出来 |
| 休闲档 | 5%，但可能被底线抬到 9 | **就是 5%** |
| 专注档 | 35%，可能被抬 | **就是 35%** |
| 那条底线的价值 | 硬挡（防看不清） | 滑杆下面一行小字：**「这张图建议不低于 9%（再低字可能发糊，糊了往右拖两格）」** |

状态行那枚读数也从「自动垫底」改名叫「**建议最低**」—— 它已经不改任何东西了，名字得说实话。

**一句话**：底线从「挡手」变成「提醒」。你要的 0~40 完整区间给你了，代价是**极少数图上拖到很低字可能发糊** —— 真糊了往右拖两格就行。字还有黑白自动判定和文字光晕兜着。

## 验证
