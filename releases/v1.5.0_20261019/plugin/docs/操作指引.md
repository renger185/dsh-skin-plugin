## 零、三十秒上手（5 步）

1. **装好**（见第一节），**重启桌面端**。
2. 屏幕右侧、输入框上沿附近会有一颗**圆形悬浮球** —— 第一次装的话，**面板会自己弹出来并显示引导**（4 步）；平时**单击**它打开面板。
3. 面板里点 **「选图片」** 或 **「整个文件夹」**，选几张喜欢的图。
4. 在**图库**里点一张 —— 它立刻变成全屏背景，界面文字颜色自动跟着变。
5. 想换回来：面板**最顶上**的 **「恢复默认界面」** 一点就还原（图库不会清）。

> 想让它自己换：**双击悬浮球** = 开/关自动换肤（球右上角出现**小绿点**就是开着）。

## 一、安装

### 1.1 方式甲：应用内安装（推荐）

1. 打开桌面端左侧的 **「插件」** 页面。
2. 点右上角的 **「添加」**，在弹出的安装窗里填来源（取决于发布者给你的形式：包名 / 本地文件夹 / 仓库地址）。
3. 装完**重启桌面端**。

> 各版本的安装窗长得不一样，**以你屏幕上那个弹窗的提示为准**；填不进去就问发你插件的人要「来源」。

### 1.2 方式乙：手动放文件（会改配置的人）

插件就是一个文件夹。放到桌面端的插件目录下，再在配置里登记：

1. 把整个 `plugin` 文件夹放到
   `%USERPROFILE%\.dsh\profiles\desktop\node_modules\@local\dsh-skin\`
   （也就是 `@local` 下面新建一个叫 `dsh-skin` 的文件夹）。
2. 打开 `%USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml`，在最外层数组里加一段：

```yaml
- insert:
    - id: dsh-skin
      name: '@local/dsh-skin'
      config:
        # 下面三个路径换成你自己的目录（插件会在这里存设置、图库、图片和音效）
        stateFile: 'D:/dsh-skin/state.json'
        libraryFile: 'D:/dsh-skin/library.json'
        imageDir: 'D:/dsh-skin/images'
```

3. 保存后**重启桌面端**。

> 三个路径的目录**不用自己建**，插件会按需创建。

### 1.3 装好了怎么确认

打开 **设置 → 外观**（或插件列表），能看到一行叫 **「换肤（Skin） v1.4.0」** 的就是装上了；屏幕上也会出现那颗悬浮球。

## 二、那颗悬浮球怎么用

| 操作 | 会发生什么 |
|---|---|
| **单击** | 打开 / 关闭面板 |
| **双击** | 开 / 关**自动换肤**（球右上角出现**绿点**＝开着） |
| **按住拖动** | 把球挪到顺手的位置；**松手会记住**，重启还在 |
| **把图片文件拖到球上** | 直接导入这张图 |
| **Esc** 或点面板外面 | 关掉面板 |

**默认位置**：输入框上沿再往上一点点（刻意不挡住右下角的发送键）。你要是拖到底边，松手时它会自己抬回输入框上沿。

## 三、面板从上到下逐项说明

### 3.1 语言 / Language

**最顶上就是它**：

- **「中文 / Chinese」**（默认）｜ **「English / 英文」**
- 两个按钮都写着中英两种字，所以不管现在是哪套语言，都看得懂、**一键切换**，切完立刻生效并记住。

### 3.2 恢复默认界面

撤掉背景图和所有颜色改动，回到没装插件时的样子。

- **图库不会清空**，随时能再选一张。
- 悬浮球的位置、语言、提示音开关这些**不会被重置**。

### 3.3 使用模式（正常 / 专注 / 休闲）

| 模式 | 背景上那层「明度」压多少 | 效果 |
|---|---|---|
| **专注** | **35%** | 背景压得实一点，字最清楚 |
| **正常** | 按每张图自己的明暗（暗图 12% / 亮图 6%），滑杆可再手调 | 折中 |
| **休闲** | **5%** | 背景几乎不压，图最大程度露出来 |

专注 / 休闲下，下面那根滑杆会**变灰**并写明「模式锁定了这一档，回到『正常』才能自己拖」。

### 3.4 背景明度（透明度）

一根滑杆，**范围 0~40%**：

- **往左 = 背景图越清楚**（0 = 原图直接透出来）；**往右 = 背景压得越实、字越清楚**。
- 拖到哪就是哪，**0 就是 0**。
- 每张图会算一条**建议最低值**，写在滑杆下面（「这张图建议不低于 9%」）。**那只是建议，不挡手** —— 字糊了往右拖两格就行。
- 松手才写盘（拖的过程不反复存）。

### 3.5 图库

- 点任意一张缩略图 = 立刻换成它；当前用的那张有**描边 + 右上角勾**。
- 一次只加载 60 张，**往下滚自动续**（图库一千多张，一次全画会卡）。
- **「换一张」**：随机抽一张（不会抽到当前这张）。
- **「选图片」/「整个文件夹」**：导入；也支持把图拖到悬浮球上。
- 打开面板时会**自动定位**到当前用的那张。

### 3.6 竖图铺法

竖图直接铺满会被裁掉脑袋。可选：**原图**（完整显示）/ **居中** / **铺满** / **模糊填充** / **立绘贴侧**。另有**两侧模糊过渡**滑杆（0 = 干脆不要那层）。

### 3.7 任务完成提示音

**默认关**，要开三步：

1. 点 **「开」**；
2. 点 **「试听」** —— 这一步同时拿到浏览器的发声授权，**不能省**；
3. 拖**音量**滑杆。

**用自己的音频**：点 **「添加音效…」**，文件框里**可以一次多选**（按住 Ctrl 点选或框选一片）。

> 装好第一次打开时，插件**已经自带三个小音效**（叮的一声 / 咚咚 / 丢硬币）—— 不用自己找，
> 不想要就在列表里 `✕` 删掉（删了不会再长回来）。

- 支持：mp3 / wav / ogg / m4a / aac / flac / webm
- **单个最大 8MB**；**总共最多 30 条、合计 200MB**（面板上那行「容量：已用 x / 上限 y · n/30 条」随时能看到）
- 加完会给一句汇总（加了几个、几个没进去、为什么没进去）
- 点一下列表里那条就是选中（`✓`），每条右边 `✕` 删掉

**什么时候响**：任务**真的结束**时响一声（放的是你选的那条，没选就是内置的「叮」）。

### 3.8 这张图的读数

显示当前这张图的：深浅（浅色图 / 深色图）、亮度、**建议最低**（就是 3.4 那条建议值）。

## 四、文字颜色为什么自己变

**自动，不用管。** 插件按图片明暗判：

- 图偏暗（黑块多）→ **白字**
- 图偏亮（白块多）→ **黑字**
- 黑白差不多 → 按主题默认

**只有黑和白两种**，没有第三种颜色。（早先有一档「白底用蓝字」的例外，实测在亮图上对比度只有 2.55:1、黑字有 11.22:1，反而更糊，已撤掉。）

## 五、常见问题

**Q：装了没反应，界面上什么都没有？**
A：① 先**重启桌面端**；② 去 设置 → 外观 看有没有「换肤（Skin） v1.4.0」那一行 —— 没有就是没装上，回头查第一节。

**Q：悬浮球找不到了？**
A：它可能被拖到屏幕边角了。**重启桌面端**会让它回到输入框上沿附近。（拖动位置会被记住，这是故意的。）

**Q：面板挡住了输入框 / 发送键？**
A：球和面板都能拖；面板会自动往空间大的那边展开。

**Q：换图后字看不清？**
A：把「背景明度」往右拖两格（地铁照、夜景这类图建议更高一点）。插件已经自动判了黑白字，仍看不清就是背景太花。

**Q：图库里的图会不会丢？**
A：不会。图片存本地文件，重启、换端口都在。「恢复默认界面」只撤背景和配色，**不清图库**。

**Q：提示音不响？**
A：三个可能：① 开关没开；② **没点过「试听」**（浏览器要求先有一次点击才允许出声）；③ 自定义音效没选中（列表里那条要有 `✓`）。都不对的话，看面板上有没有一行红字写「自定义音效没播出来（…）」，把那句发给开发者。

**Q：提示音提前响了？**
A：v1.3.4 起已经修过三种「假完成」（维护中、子任务先完、短促抖动）。要是还遇到，记一下**早多久**（几秒 / 几分钟）告诉开发者。

**Q：加音效说「条数满了 / 总量放不下」？**
A：上限是 30 条 / 200MB。删几条或用小一点的音频（提示音 1~3 秒的 mp3 通常只有几十 KB）。

**Q：怎么切英文？**
A：面板**最顶上**「English / 英文」一点就切，记着呢。

**Q：能同时设好几张背景轮播吗？**
A：「背景图片随机变换时间」里选间隔（最短 1 分钟）就自动换；库里至少要有 2 张图。

## 六、不想要了：还原 / 卸载

- **只想还原界面**：面板最顶上 **「恢复默认界面」**（图库和设置都留着）。
- **彻底不用了**：
  1. 面板最顶上先点一次「恢复默认界面」；
  2. 桌面端左侧 **「插件」** 页面里把 `dsh-skin` 关掉/删掉（手动装的就去 `node_modules\@local\` 删掉那个文件夹，并把 `cordis.patch.yml` 里那段删掉）；
  3. **重启桌面端**。

## 七、English quick start

**Install** → restart the desktop app → a round **floating ball** appears near the input box on the right.

- **Click** the ball to open the panel. **Double-click** toggles auto-rotate (a **green dot** on the ball means it is on). **Drag** it anywhere (position is remembered). **Drop an image file on it** to import.
- **Panel, top to bottom**: **Language** (中文 / English, one click) → **Restore default look** → **Mode** (Focus 35% / Normal per-image / Leisure 5%) → **Brightness (wash) slider, 0–40%** → **Gallery** → **Portrait fill** → **Completion chime** (off by default: switch it **On**, then press **Test** once — the browser needs one click before it will make any sound) → **This image** info.
- **Text colour is automatic**: dark image → white text, light image → black text. Only black and white.
- **Sound limits**: 8MB per file, 30 files / 200MB in total.
- **Full guide**: this document (`操作指引_20261019_2115.md`).

## 八、文件与路径索引

| 装什么 / 存哪 | 位置 |
|---|---|
| 插件本体 | `%USERPROFILE%\.dsh\profiles\desktop\node_modules\@local\dsh-skin\` |
| **插件自带文档** | 插件文件夹下的 `docs\`（操作指引 / 使用说明 / 版本记录 / 踩坑与设计决策） |
| **插件自带音效** | 插件文件夹下的 `assets\sounds\`（首次会拷三个到下面的 sounds 目录） |

| 设置 | `<imageDir 的父目录>\state.json`（默认由安装时那三个路径决定） |
| 图库索引 / 图片 | `library.json` + `images/`（一张图两个文件：原图 + 缩略图） |
| 自定义音效 | `sounds/`（索引 `index.json`，每个音效一个文件） |
| 版本与文件清单 | 发布包里的 `releases/v<版本>_<日期>/文件清单.md`（含每个文件的 SHA256） |
