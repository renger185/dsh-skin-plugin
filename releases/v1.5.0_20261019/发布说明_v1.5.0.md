## 二、自带三个小音效

装好第一次打开，音效列表里**已经有三个**：**叮的一声 / 咚咚 / 丢硬币**。不用自己找，不想要就删掉（删了不会再长回来）。

## 三、文档跟着插件走

插件文件夹里多了 **`docs/`**：操作指引 / 使用说明 / 版本记录 / 踩坑与设计决策 + 目录页。
由脚本从工作区真源**单向同步**（带对账），避免两处各改一份越漂越远。

## 四、脱敏 + 打包发布工具链（推送前必过）

| 工具 | 干什么 |
|---|---|
| `verify/make_publish.cjs` | 挑该出门的文件 → 打 `publish/` → 把个人痕迹**只改副本**（工作区原文件一个字节不动） |
| `verify/check_publish_sanitization.cjs` | 13 类私人痕迹 + 6 类私人数据目录 + **改写过的 JS 必须仍能编译** + 该在的文件在不在 |

**实测**：

- publish 共 **144 个文件 / 3.4MB**；13+6 项判据**全 OK**；**40 个 JS 全过编译**；
- 你那份通用脱敏脚本（`remote-gateway\tools\check-publish-sanitization.ps1`）对这个包也是 **[OK]**；
- **干净环境实测**：把 publish 拷到空目录，10 个自带脚本全过（`full_verify` 在没有私人数据时自动用内置样例）。

**没进包的**：你的壁纸库（1387 张 456MB）、`state.json`、`library.json`、你的截图、备份文件 —— 全在 `.gitignore` 和自检里挡着。
