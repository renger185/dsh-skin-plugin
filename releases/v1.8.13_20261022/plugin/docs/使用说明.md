# 换肤插件 · 使用说明

dsh-skin —— 给 DeepSeek Harness 桌面端换背景皮肤，并让界面文字自动保持清晰。

当前版本 **v1.6.0**（2026-10-20）。这一版：撤掉了 CS / QQ 那 5 条品牌音效（自带音效剩 4 条，老装机里已铺的会自动清掉），仓库首页补上了 4 张成品效果图。

---

## 一、它能做什么

| 功能 | 说明 |
|---|---|
| **换背景图** | 支持选单张或整个文件夹。横图自动铺满屏幕，竖图按原图比例显示并在两侧做模糊过渡 |
| **文字自动配色** | 按图片明暗自动选黑字或白字，保证文字在背景上看得出。不用手动调 |
| **悬浮球 + 面板** | 屏幕右侧一个圆形入口，点开是图库和全部设置 |
| **自动换肤** | 按时间间隔自动换图（双击悬浮球开关） |
| **任务完成提示音** | 任务跑完响一声提醒。内置合成音，也能加自己的音频（可多选批量加） |
| **设置不丢** | 所有设置和图库存成本地文件，重启、换端口都在 |

---

## 二、快速上手

### 1. 打开面板

点屏幕上的**圆形悬浮球**（默认在输入框上沿附近，不挡发送键）。

### 2. 加背景图

面板里点 **「选择图片」** 或 **「整个文件夹」**，选中后自动入库。也支持**把图片文件直接拖到悬浮球上**。

### 3. 选一张当背景

面板往下拉是图库，点任意一张缩略图立刻切换。当前用的那张有**描边 + 右上角勾**。

图库一次只加载一部分，往下滚会自动续；也可以点 **「换一张」** 让系统随机抽一张（不会抽到当前这张）。

### 4. 不想用了

面板**最上面第一个**就是 **「恢复默认界面」** —— 撤掉背景和所有颜色改动，回到没装插件时的样子。**图库不会清空**，随时能再选一张。
（原来它吊在面板最底下，要滚到底才够得着；10-19 18:xx 按你的要求挪到最上面了。）

## 三、各项设置

### 背景明度（遮罩深浅）

一根滑杆，**往左 = 背景图越清楚，往右 = 背景压得越实、字越清楚**。拉到 0 就是原图直接透出来。**范围 0~40%**（10-19 19:xx 从 0~25 放开）。

- 滑杆**拉不到头**：每张图下面有一条最低线（字会看不清的下限），拖不过去，这是保底不是审美选项。
- **它跟上面那三个模式是一回事**：专注 = **35%**、休闲 = **5%**、正常 = 按每张图自己的明暗（暗图 12% / 亮图 6%）再让你手调。
- 在**专注 / 休闲**模式下，这档由模式定死，滑杆会变灰并写着「模式锁定了这一档，回到『正常』才能自己拖」。
- 三个模式都还能用（10-19 19:xx 修好：前一版把滑杆删了，结果三个模式全成了摆设，同一天补回来的）。

### 文字颜色

**自动，不用管。** 系统按图片明暗判：

- 黑块占得多 → 白字
- 白块占得多 → 黑字
- 黑白差不多 → 按主题默认

**只有黑和白两种，没有第三种颜色。** （早先有一档"白底用蓝字"的例外，10-19 16:xx 已撤掉 —— 实测那档在亮壁纸上只有 2.55:1 的对比度，黑字是 11.22:1，等于把字调糊了。）

### 竖图铺法（只有竖图才有）

| 选项 | 效果 |
|---|---|
| 原图 | 按原图像素显示，不放大不裁切（默认） |
| 居中 | 完整显示，不铺满 |
| 铺满 | 放大铺满，可能裁掉边缘 |
| 模糊填充 | 放大模糊后作背景，原图叠上面 |
| 立绘贴侧 | 贴屏幕右侧，左侧留给界面 |

下面还有一条 **「两侧模糊过渡」** 滑杆（0-64px）：竖图和屏幕两侧之间那层模糊的半径。拉到 0 就是干净过渡，不要这层。

### 自动换肤

| 档位 | 间隔 |
|---|---|
| 关 | 不自动换 |
| 预设档 | 1 / 5 / 15 / 30 / 60 分钟 |
| 自定义 | 1 分钟到 24 小时之间任意填 |

开着的时候，悬浮球右上角有个**小绿点**，一眼知道是开着还是关着。
**双击悬浮球**可以直接开关自动换肤，不用打开面板。

### 任务完成提示音

**默认关。**

1. 点 **「开」**
2. 点 **「试听」** 听一声（这一步同时取得播放授权，之后自动响才不会被拦）—— **这一步不能省**：浏览器规定页面必须先被点过一次才允许出声
3. 拖 **音量** 滑杆调到合适

**两种情况都会响一声**（内置合成「叮」，或你自己选的那条音效）：

1. **任务真的跑完**时；
2. **需要你判断**时 —— 工具要你**批准**、或者要你**回答问题**（它卡住等你动手那一刻）。

> 10-19 19:xx 修了一个一直存在的毛病：**任务完成了从来不响**。根因是页面问主机「完成了没」用的方式和主机端回话的方式对不上（页面用"提交"去问，主机端那条分支只回一句"收到"、不带时间戳），所以页面永远以为没完成。**试听会响是因为它绕过这条路直接播** —— 已修好，重启桌面端后按上面 1、2 步开一次就能用。

**想用自己的音频**：点 **「添加音效…」**，在弹出的文件框里**可以一次选多个**（按住 Ctrl 点选，或者框选一片），一次全加进去。

- 支持格式：mp3 / wav / ogg / m4a / aac / flac / webm
- **单个文件最大 8MB**（提示音用不了更大；8MB 约等于 128k 的 mp3 八分半钟）
- **总共最多 30 条、合计 200MB** —— 面板上那行「容量：已用 x / 上限 y · n/30 条」随时能看到还剩多少
- 一次选多个时，加完会给你一句汇总：加了几个、几个没进去、没进去是因为格式不对 / 超 8MB / 条数满了 / 总量放不下
- 添加后会列在面板里，**点一下那条就是选中**（再点一下取消选中，回到内置音）
- 每条右边 **✕** 删掉；如果删的是正在用的那条，会自动退回内置音
- 音频存在本地文件里，**重启、换端口都不丢**

## 四、常见问题

**Q：换图后文字看不清？**
A：系统已经自动判了黑白字。如果某张图还是看不清，把图名告诉开发者 —— 那可能是需要单独调的特殊图。

**Q：悬浮球挡着输入框的发送键？**
A：默认位置已经抬到输入框上沿。如果还挡着，**直接把球拖到别的位置**，松手后位置会被记住，重启也在。拖到底部区域会被自动抬回输入框上沿。

**Q：深色主题下看着有点糊？**
A：已知情况。深色主题为了保证文字可读，垫底会比浅色主题厚一些。

**Q：提示音不响？**
A：三个可能：① 开关没开；② 没点过「试听」（浏览器要求先有一次用户点击才允许播放声音）；③ 自定义音效没选中（要看到那条前面有 ✓）。

**Q：添加音效失败？**
A：面板上会显示具体原因：格式不支持 / 单个超过 8MB / 音效条数已满 30 条 / 总容量超过 200MB。按提示换个文件、或者先删掉几条再试。

**Q：设置会丢吗？**
A：不会。设置、图库索引、图片、音频全部存成本地文件。卸载插件才会清。

**Q：图库一次显示不完？**
A：设计如此。一次只加载视口附近的一部分，往下滚自动续 —— 这样 1387 张图的库切换也很快。

## 六、技术说明（简短）

- 插件分主机端和页面端两半，中间靠本机接口通信
- 设置存 `state.json`，图库索引存 `library.json`，图片和音频各自存目录
- 音频：单个 8MB 封顶、最多 30 条、合计 200MB 封顶（页面和主机端各拦一道）
- 音频一条一个文件存在 `sounds/` 目录里，索引记 `{id, 名字, 后缀, 字节数, 时间}`；播放时按 id 现取，不占内存
- 文字配色在图片入库时就算好（切块统计明暗占比），切换时不重算
- 所有主题改动都通过应用官方留的主题变量接口写入，不改应用本体
