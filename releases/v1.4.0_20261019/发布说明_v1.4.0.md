## 一、语言开关（面板最顶上）

面板从上到下现在是：

**① 语言 / Language** ← 新加的，在最顶上
② 恢复默认界面
③ 使用模式（正常 / 专注 / 休闲）
④ 背景明度（0~40%）
⑤ 图库
⑥ 竖图铺法
⑦ 任务完成提示音
⑧ 这张图的读数

- 两个按钮写着**中英两种字**：**「中文 / Chinese」**、**「English / 英文」** —— 不管现在是哪套语言，这两个按钮都看得懂，**不用先猜再点**。
- **一键切换**：点一下就换，立刻生效，**并且记住**（下次打开还是这套语言）。
- **默认中文**（你要的）：新装、老存档、配置坏掉，一律先给中文。
- 「恢复默认界面」**不会把语言重置** —— 语言不算界面配色。

## 三、验证

新增 `verify/panel_order_check.cjs`（10 项）：

- 语言开关**必须在最顶上**（比对面板各段在源码里的先后顺序）；
- 两个按钮的中英字样、**默认中文**、一键切换 + 落盘、`dictFor` 认面板选择；
- 「恢复默认」不动语言；主机端也归一化 `lang`；
- **中英两套文案的键集合必须一致** —— 实测 **中 66 / 英 66 键**，一把钥匙都不缺（缺了切到英文就会看到 undefined）。

全套 **15 个脚本**退出码全 0；版本对账三处（版本号 / 快照哈希 / 界面标题）全对。

## 四、你要做的

**重启桌面端** → 设置 → 外观应显示「换肤（Skin） v1.4.0」；打开面板，**最顶上就是语言开关**。

给朋友的时候，把插件文件夹 + `操作指引_20261019_2115.md` 一起发过去就行。
